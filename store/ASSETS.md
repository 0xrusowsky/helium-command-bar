# Chrome Web Store asset checklist

The following assets must be captured or designed before submission. Do not place promotional claims, ratings, or Chrome Web Store badges in the images.

## Required preparation

- [x] 128×128 store icon: use `icons/icon-128.png`.
- [ ] At least one 1280×800 PNG or JPEG screenshot.
- [x] 440×280 small promotional tile: `assets/small-promo.png`.
- [x] 1400×560 marquee tile: `assets/marquee-promo.png`.
- [ ] Optional YouTube demonstration video.

Verify the current requirements shown in the Developer Dashboard at submission time; Google may change which promotional fields are mandatory.

The promotional PNGs are generated from their SVG sources with `npm run store-assets` on macOS.

## Recommended screenshots

Capture at 1280×800 without personal bookmarks, account names, private URLs, notifications, or other identifying content.

1. **Command bar search** — several safe example tabs, with a matching open tab selected.
2. **Split-aware results** — a Helium split displayed as one complete block.
3. **Bookmarks and recently closed** — all three result sections visible.
4. **Settings** — theme presets, result ordering, and duplicate cleanup.
5. **Tab viewer** — Control-Tab viewer displaying normal and split tab blocks.

## Recommended promotional copy

### Small tile

**Helium Command Bar**

Search tabs. Navigate splits. Stay on the keyboard.

### Marquee tile

**A keyboard-first command bar for Helium**

Open tabs, favorites, recently closed pages, and split navigation in one place.

## Before capturing

- Use the neutral default theme unless another theme has stronger contrast.
- Populate tabs with public demo sites only.
- Hide unrelated toolbar extensions where practical.
- Ensure text is readable at the uploaded resolution.
- Avoid screenshots of protected or private browser pages unless needed to explain setup.
