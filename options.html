Default split view appearance

Press → to enter individual tab navigation and ← to return to the complete split group. Compact mode expands and collapses visually as you do.

Split focus emphasis

Make the focused pane more obvious whenever you use a split view.

This optional feature requires access to webpages in split panes. Helium describes that permission as “read and change data on all websites,” although the extension only injects pointer-events-free ring, dim, and blur layers. Protected browser pages cannot be highlighted, dimmed, or blurred.
