Keyboard navigation

Use familiar shortcuts while treating every split as one tab block.

Use Command-T for the command bar

Import the core mappings to translate Command-T to the extension's Command-Shift-Space bridge, plus Option-T, Ctrl-Tab, Ctrl-Shift-Tab, Ctrl-J/K aliases, and Ctrl-H/L. Each rule remains opt-in inside Karabiner-Elements.

Import core shortcuts

Chromium cannot automatically assign an extension to its protected Command-T shortcut, so Karabiner provides the user-facing default without manual extension configuration. Command-T replaces Helium's normal new-tab behavior when enabled; Option-T continues to create a native split.
