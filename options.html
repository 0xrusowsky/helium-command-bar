Default split view appearance

Choose how split tabs appear whenever the command bar opens or the query changes.

Default split view appearance

Press → to enter individual tab navigation and ← to return to the complete split group. Compact mode expands and collapses visually as you do.

Inactive split pane

Make the focused pane more obvious whenever you use a split view.

This optional feature requires access to webpages in split panes. Helium describes that permission as “read and change data on all websites,” although the extension only injects a pointer-events-free visual layer. Protected browser pages cannot be dimmed or blurred.
