# Privacy Policy for Helium Command Bar

**Effective date:** July 28, 2026

Helium Command Bar is a keyboard-driven tab and split-navigation extension for the Helium browser. This policy explains what information the extension accesses and how it is used.

## Information the extension accesses

To provide its features, Helium Command Bar accesses the following information inside the browser:

- open-tab titles, URLs, favicons, activation state, and split membership;
- browser bookmarks selected for display as favorites;
- recently closed tabs and windows;
- extension preferences, such as appearance, result ordering, duplicate-tab cleanup, and split-navigation state;
- search text or URLs that the user explicitly enters into the command bar.

If the optional split focus-emphasis feature is enabled, the extension receives permission to inject a visual focus or blur layer into webpages. The injected layer does not read, collect, or modify page content and does not intercept pointer input.

## How information is used

This information is used locally to search and activate tabs, navigate split views, display bookmarks and recently closed tabs, remove duplicates when requested, restore sessions, and apply user preferences.

When a user explicitly submits a web search, the search text is sent to the search provider configured in the browser. That provider processes the request under its own privacy policy. Opening a URL sends the normal browser request to that destination.

Choosing the optional Karabiner import link opens a user-initiated link to the project's public GitHub repository. The extension does not download or execute remote program code.

## Data collection and sharing

Helium Command Bar:

- does not transmit browsing activity, bookmarks, or recently closed tabs to the developer;
- does not operate analytics, telemetry, advertising, or tracking services;
- does not sell or share user data with third parties;
- does not use user data for purposes unrelated to its visible tab-management features.

Extension preferences may be stored using Chromium's synchronization storage and may therefore be synchronized by the browser according to the user's browser-account settings. Browser bookmarks may likewise be synchronized by the browser. The developer does not receive this synchronized data.

## Data retention and control

Browsing information is processed transiently in the browser. Preferences remain in browser extension storage until changed, cleared, or the extension is uninstalled. Users can disable the optional webpage permission at any time in the extension settings or browser extension controls.
